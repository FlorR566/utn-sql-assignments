# UTN - SQL Assignments

El repositorio combina las tareas, trabajos prácticos y guías de ejercicios desarrollados en Base de Datos I en la **Universidad Tecnológica Nacional (UTN)**.

El objetivo de este repositorio es consolidar mis conocimientos en diseño de bases de datos relacionales, normalización y optimización de consultas SQL.

---

## Tecnologías y Herramientas Utilizadas

- **Motor de Base de Datos:** MySQL
- **Entorno de Desarrollo:** MySQL Workbench / Terminal
- **Conceptos Aplicados:**
  - Modelado de datos (Diagramas Entidad-Relación - DER)
  - Normalización de tablas (1FN, 2FN, 3FN)
  - Lenguaje de Definición de Datos (DDL) y Lenguaje de Manipulación de Datos (DML)
  - Consultas complejas, JOINS, subconsultas y funciones de agregación
  - Creación de Índices y Vistas (Views)
